# ADR-NNNN: Short title in the imperative

- **Status:** Proposed | Accepted | Superseded by ADR-NNNN
- **Date:** YYYY-MM-DD
- **Deciders:** who agreed to this
- **Amended:** YYYY-MM-DD — what changed and why _(optional; a decision may be amended without being replaced)_

`**Status:**` appears exactly once per ADR, in this block. An appended
`## Amendment (…)` section labels its own state `**Amendment status:**` instead,
so a machine reading this file never picks up the amendment's state as the
ADR's own.

## Context

What situation forces a decision now? State the facts, including the ones that
argue against the decision taken. Reference concrete files and line numbers
rather than describing the code from memory.

## Decision

What is being decided, in the active voice. Be specific enough that a reviewer
can tell whether a given pull request violates it.

## Consequences

### What this enables

### What this costs

Name the real price — the thing that becomes harder or slower. An ADR with no
costs listed has not been thought through.

### What is now forbidden

The rules a future change must not break, phrased so a reviewer can check them.
Required: an ADR that forbids nothing has not stated its boundary.

## Alternatives considered

Each with the reason it was rejected. "We didn't think of it" is a valid reason
to add one later; silence is not.
